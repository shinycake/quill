Quill is an unofficial Telegram client and still in beta.

### Faster launch on macOS

- The window now opens while macOS is still finishing the launch, and the chat list is already in its first frame. Quill shows up sooner after a Dock click, most of all on the first launch after a restart.
- Work the first frame doesn't need now runs after it or on another thread, such as reading the keyboard layout, building the menu bar and the tray icon, and listing the displays and GPUs. Theme setup no longer waits for the list of installed fonts.
- The text of the chat list draws from the glyphs the last launch saved, instead of drawing every one again.

### Boxes instead of panels

- Forwarding opens a box: the search field takes focus so you can type right away, Saved Messages comes first, and each chat shows whether the person is online or how many members it has. A chosen chat gets a check on its photo, and the comment field appears once you pick one. The ⋯ menu by Send hides sender names or captions, sends without sound, or schedules the message.
- Reply in Another Chat, a chat's notifications, the auto-delete timer and the folder picker open as boxes too. Notifications now also opens from a chat-list row when no chat is open.
- The poll, checklist, Add Link, Choose Date, code language and Send Contact boxes open over the window. Their main button stays in view however long the content gets. The poll box asks for the question first.
- Stop Poll and Close Secret Chat ask in a confirm box.
- Send as opens a menu next to your photo in the composer.

### Chats

- Telegram links in messages and link previews open in Quill, for example emoji packs and sticker sets. Links Quill has no screen for still open in the browser.
- Toasts, the reply and pinned bars, the emoji panel and the corner buttons fade and slide instead of popping. The ↓ button sits in the bottom-right corner.
- Voice messages have a small transcribe button next to the waveform, so the bubble doesn't get taller.
- Reply and forward headers use the message's text size.
- Sponsored messages are no wider than a message bubble.
- Deleting a paid suggested post before its minimum time is up warns that the Stars will be lost. Before, the warning never showed.

### Chat list, calls and contacts

- Empty, loading and failed screens share one look, with a button where one helps: New Message, Edit Folder or Retry.
- Search filters fit on one row, as two menus. While a search runs, the hint says what it's looking for.
- Calls shows repeat calls with the same person as one row with a count, missed calls in red, and a button to call back.
- The sort button in Contacts was blank. It shows now.
- Pop-up menus have the theme's border and shadow instead of an accent outline.

### Settings

- Devices lists each session with a picture of its device, opens a session's details in a box, and asks before ending sessions.
- Data and Storage, Folders, Language, Advanced, About, Chats, Battery and Appearance use the same grouped rows as the rest of Settings.

### Groups and profiles

- Setting a photo while creating a new group now works.
- Group Info no longer shows a Members row above the member list.
- The media viewer's zoom buttons use icons, and Reset is dimmed when the picture already fits.

### Sign-in

- The sign-in steps show the app icon. The country list drops down over the card, and Enter picks the first match.

### Wording

- Status messages start with a capital letter, and messages that used developer terms now use plain words.

### Not yet tested on a live account

- Most of the new boxes and settings pages were checked with tests and offline demos. The launch changes were measured on one Mac with a real account.
