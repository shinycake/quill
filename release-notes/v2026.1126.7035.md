Quill is an unofficial Telegram client and still in beta.

### A new Floating layout

- Quill has a second layout, **Floating**. Your chat wallpaper fills the whole window, and the chat list, chat header and message box float over it as rounded cards with soft shadows and no divider lines. Messages sit in a centred column (#1510).
- You can pick a layout in the welcome screens or any time in **Settings › Appearance › Layout**. **Classic** stays the default and looks the same as before (#1510).
- In Floating, the pinned message and the other bars under a chat's title share one card with the title. The open chat shows as a solid accent row, and search and folder tabs are pills (#1510).
- In a narrower window, the chat list slides in over the chat as a drawer. In a very narrow window, Quill shows one column (#1510).
- Menus and pop-ups have rounded corners and grow in when they open. Switching chats slides the messages across, folder pages slide in tab order, and the message box grows smoothly as you type. Turning on reduce motion in your system settings, or Quill's power-saving switch, turns these off (#1510).
- With **Glass effects** on, the Floating cards turn into glass. Glass on the cards costs more drawing time than glass in Classic, and the setting's description says so (#1510).
- Choosing Floating offers Quill's default pattern wallpaper if your chats don't have one (#1510).

### Fixes and polish

- Glass effects have a clearer liquid look, with a thin edge and less frost (#1508).
- Opening the first chat after launch no longer flashes a light colour behind a dark-theme pattern wallpaper (#1506).
- Clicking the photo in a profile card opens the photo viewer on top of the card instead of underneath it (#1505).

### Not yet tested on a live account

- These changes were checked with tests, CI on all three systems and offline demos on macOS, not on a live account. The new drawing code for Floating was not run on real Windows or Linux graphics hardware.
