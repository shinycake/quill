Quill is an unofficial Telegram client and still in beta.

### Downloads

- Downloaded documents now land in your download folder (#1488 by `@pgiacome`, with review fixes). Downloading a file from a chat copies it to the folder set in Settings, or asks where to save it if you turned on "Ask where to save". The copy goes where you chose at the moment you clicked, even if you change the setting while it downloads. Files from protected chats and self-destructing messages are not copied.

### Emoji status

- You can now remove your emoji status from a custom emoji's menu (#1489). Right-click a custom emoji in the emoji panel or in an emoji pack and pick Set Status or Remove Status. Removing it shows a short "Emoji status removed" note with Undo.

### Not yet tested on a live account

- Both changes were checked with tests and offline demos, not on a live account. A download that resumes after a restart finishes without the copy in the download folder.
