Quill is an unofficial Telegram client and still in beta.

### New

- A bot's streamed reply appears line by line, the way Telegram Desktop shows it. Words stay in place while the text sweeps in, and the bubble grows smoothly with it.
- A bot's Menu button opens its command list above the field instead of typing a slash. Click or Enter sends a command and keeps your draft, and Tab puts it in front of your text.
- Message widgets fill their bubble edge to edge, following Telegram's widget spec.

### Fixes

- Opening a chat with a message widget no longer closes Quill on Windows (#1425).
- A channel's ad no longer pulls the view back down when you scroll up (#1427). Ads now sit in the history like posts, placed where Telegram Desktop places them, and scroll with everything else.
- Inline bot buttons fit inside the message. Long labels end in "…" and show in full on hover, and buttons have a soft fill so they read as buttons.
- Inline bot buttons spin while the bot answers and ignore repeat presses. A bot's alert answer opens a small alert box.
- A media tile follows the bubble's small corners.
- A widget link opens in the window where you pressed it, and a widget shown in two windows no longer flickers between two widths.
- A pinned chat drag ends cleanly when Contacts, Calls, search or another folder takes over the list.

### Faster cold starts on macOS

- After a restart, macOS checks each code file of a notarized app again on first use. Quill now loads its bundled libraries off the main thread's path, and an update Quill installs itself has those checks done once while it downloads, so later cold starts skip them.

### Reliability

- One more review round for hidden states that can get stuck, with 22 fixes. Answers now apply only to the request that asked for them, and a late forward answer can no longer close a newer forward.

### Not yet tested on a live account

- The ad placement, widgets on Windows and the streamed reply were checked with tests, CI on Windows and offline demos, not every case on a live account.
