### Smoother emoji effects

- The effect that plays when you tap an animated emoji like 👏 or 😂 no longer stutters. When an effect is too heavy to draw at 120 fps, it now plays at its own 60 fps, and every frame stays on screen for the same length of time.

### Also new

- Chats open at the first unread message, with the unread bar at the top, and messages count as read only once they're on screen.
- The update button now sits in the title bar as one compact pill.
- Agent access: window control no longer refuses to start when no screen reader is running, and a message an agent sends from the message box clears the draft.
