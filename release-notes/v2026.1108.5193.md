Quill is an unofficial Telegram client and still in beta.

### Fixes

- Quill no longer crashes about a second after its window opens on macOS 14 Sonoma. The crash came from stopping the window's display link while it was still drawing.
- If Quill does crash, its crash report now lists where it happened on macOS and Windows. Before, the macOS report could be empty.
- Story videos play. Downloaded clips were blocked from the player, so the viewer froze instead of showing the story. A clip that never arrives now falls back to the picture.
- Locking Quill with a chat window open no longer keeps both windows redrawing and a CPU core busy for the whole lock.
- Clicks on a menu, box or panel no longer reach what is under it. Before, clicking inside the story composer could close it and drop the draft, a toast click could close the media viewer, and clicking a story closed the viewer.

### Main menu

- The main menu is a grid of icons with a filter field. Type to narrow it, use the arrow keys to move and Enter to open.
- Entries the window already has elsewhere are gone from it: Contacts and Calls are the tabs above the chat list, Saved Messages is pinned in the list, New Story is the + in the stories strip, and New Secret Chat is in a contact's profile menu. New Community moved into the Communities box.

### Reliability

- A message that failed to send no longer shows as delivered after a restart.
- A second incoming call no longer disappears when the current call ends, and "Hanging up" can't get stuck.
- Rejoining a group call or a live stream is more reliable, and repeated rejoin requests no longer stack.
- On Linux, notification clicks, inline replies and call answers act on the right account.
- "Jump to latest" fills in missing history again, and "Jump to root" in a thread stays where it jumped.
- Leaving a chat while editing a message no longer leaves the "Cancel editing?" box open.
- "Play once" from a story reply no longer carries over to the next voice message.
- If Telegram doesn't confirm a logout, Quill now says so instead of showing Connecting forever.
- A mini-app payment that was closed while it was still being sent now shows as pending, not cancelled.

### Switching accounts

- Everything on screen now belongs to one account and is replaced whole when you switch. Before, some boxes and timers carried over:
  - The Account box could reopen over the next account, ready to delete or log it out.
  - A closed call window could hide the next account's call window.
  - The chat-window save timer could wipe another account's saved windows.
  - A Reschedule picker or the scheduled messages list could act on another chat.
- Screen sharing no longer stops working until a restart.
- A second checkout no longer takes the first payment's result.
- The Attached Stickers box and Saved Messages no longer spin forever.
- Member search no longer shows an older query's results, and Recent Actions keeps refreshing.
- Data and Storage limits, the Language page and the Settings page itself follow the account you switch to, so one account's limits are no longer saved to another.
- A poll or checklist box can no longer post to a different chat opened under it.
- Picture-in-picture opened from a chat window now closes on passcode lock and logout, like the main window's.
- AI compose in a chat window writes into that window.
- Saved Messages, global search, the group link check and Send Location try again after a failure instead of staying stuck.

### Not yet tested on a live account

- The menu grid, the click fixes, the story video fix and the account and reliability fixes were checked with tests and offline demos, not a live account, real notification daemons or two real call clients. The macOS 14 fix was tested on a macOS 14 virtual machine.
