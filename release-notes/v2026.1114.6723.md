Quill is an unofficial Telegram client and still in beta.

### New

- Settings › Language now lists the community languages Telegram still marks as beta, such as Vietnamese, Japanese, Swedish and Hungarian, under their own Beta heading with how much of each is translated (#1462). Until now they could only be opened with a t.me/setlanguage link.
- Settings shows each update's release notes as formatted text (#1456).

### Security

- Message widgets are hardened to match Telegram's widget security fixes this week (#1459). The widget engine is on the versions Telegram Desktop pins today. Quill also adds its own checks on widget storage, links, images, transforms, emoji and canvas sizes.

### Fixes

- Translate now goes to the language Quill's interface is in, including beta languages like Vietnamese, instead of English. The translate box's language button says which language it translates to, and Settings › Language has a Translate To row for the default (#1464).
- After you press Esc on emoji or mention suggestions, the same text no longer stays hidden in later messages and other chats.
- Closing the folder editor, or the Manage topics dialog, while a save is going no longer hides the result. A toast says whether it worked. Cancel in the topic editor waits for a create or save to finish.
- Story statistics on a channel's statistics page and in the story viewer no longer get stuck on "Loading statistics".
- A mini app asking to message you no longer hears "busy" forever after the request was lost.
- Turning desktop notifications off now covers every account, including ones not running at the time.
- A new message for another account flashes the taskbar or bounces the Dock right away, even while the window is hidden.
- Disconnecting one agent that sent no name in Agent access no longer blocks other unnamed agents.
- A group call rejoin that can't be sent counts toward the retry limit instead of retrying with no end.
- A widget whose engine crashes shows as failed instead of freezing.

### Reliability

- Three more review rounds for hidden states that can get stuck (#1455, #1458, #1460). Every finding was fixed or checked and shown not to be a bug.
- Rust 1.100 (#1457).
- Story viewer and settings tests no longer fail on a busy machine.

### Not yet tested on a live account

- The fixes above were checked with tests and offline demos, not on a live account.
