   - Scenario: type "cat", clear the field before SEARCH_DELAY ends. The empty branch returns (the tab is not yet Search, so it does nothing), but the timer is still held. It fires, `fire()` yields "cat", and the pack search runs over an empty field and replaces the list the user restored.
   - Fix: call `self.pickers.emoji_set_debounce.cancel()` at the top of the function, before the empty check. `gifs_ui` is fine because its empty path goes through `choose_gif_section`, which cancels.
2. File-complete: non-test one-shot dialog cells `Rc<RefCell<Option<_>>>` with `borrow_mut().take()` remain in touched files, the same shape as 12-A015.
   - src/ui/emoji_sets.rs:411

   - Fix: use `Cell<Option<_>>` and `take()`, as in the other boxes.
3. File-complete: src/ui/chat_window/slot.rs:311 (`swap_slot`, `slot.borrow_mut()`) and :438 (`slot.borrow()`) are non-test RefCell borrows in a touched file. The fix is `try_borrow_mut`/`try_borrow` with a skip, or a design that needs no cell.
4. File-complete: src/ui/send_effects/mod.rs:346, `open.areas.cells.borrow()` in `choose_send_effect`, is non-test. Use `try_borrow`.
5. File-complete: sleeps in tests of touched files, which break the "no sleeps" rule.
   - src/ui/playback_state.rs:569 (`std::thread::sleep(250 ms)` in `the_bar_follows_consumed_frames_not_the_wall_clock`)
   - src/ui/pull_next_ui_tests.rs:159 (`std::thread::sleep(READY_DWELL_MS + 30)`)
   - Fix: use the manual clock (`with_manual_clock`) and the machine's `now` argument instead.
6. Left in implicit shape: 12-C014. `ReplyPanel` is only a derived read over two stages that still live in two owners (`ChatUi::quote_picker` and `ShareStage::ReplyChooser`). One function keeps them exclusive by hand, so the shape is unchanged. Hold the open panel as one value in one owner (for example in the share stage), or skip it with a sound reason.
