## Confirmed defects

1. src/ui/glyph_sweep.rs:121 (`window_activation`) with `begin` (:147): the "left the foreground" mark is lost while a sweep is `Marked`. Old code set `trigger = Left` unconditionally and `begin` returned early on `Marked` before taking it, so the mark survived. New code only sets `Sweep::Left` when the stage is `Idle`. Scenario: an idle trim marks the window, the user switches away and minimises before another frame starts. The mark is then given up after two trims, the stage goes to `Idle` and `Left` is gone. The "any emoji are worth a sweep once the window left" rule never runs, so the emoji kept by a closed panel stay in the atlas. Fix: carry the left-flag inside `PendingSweep` (`left: bool` set by `window_activation` on `Marked`, honoured when the mark is given up), or fold `Left` into the `Marked` stage.
