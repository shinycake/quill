## Failures

1. **src/ui/notify_windows/mod.rs:871-877 (`notify_windows_tick`, the `closed` branch then `if animating`). The "Hide all" window stays on screen when the last popups close in one step.**
   - **Trigger:** two notifications are up (so the hide-all window shows, `hide_all_wanted(2, 0)`), both `WaitingForInput`. The user comes back: one `notify_check_input` gives both the same `hide_at = now + WAIT_LONG_HIDE_MS`; at that time both start their slow fade together and finish in the same tick. That tick: `closed` -> `retain` empties `shown` -> `notify_show_next` -> `notify_restack` calls `hide_all.hide(false, now)` (a new fade starts), and `ensure_notify_clock` returns early because the running step is due. `animating` was computed in the loop before the restack, so it is false; `next_step(now)` finds no shown popup, nothing waiting, no deadline -> `Clock::Stopped`. The hide-all window keeps full opacity and is never closed until an unrelated event (a new notification, a hover). In the base the `None if open` arm stepped again 300 ms later and finished the fade; this round removed that arm (correctly, per r4 item 2) without replacing what it masked. The same ordering also stalls a slide the restack starts while a remaining popup has a deadline (pre-existing: the slide and the hide-all fade wait for that deadline and then jump).
   - **Fix:** a restack starts new animations, so the step after a close must run a frame later: in `notify_windows_tick`, return `Some(FRAME)` when `animating || closed` (or recompute `animating` from `shown`/`hide_all`/`samples` after `notify_show_next`). The next step sees the new shift/opacity animations and steps per frame until they end, then `next_step` stops the clock as now.
   - **Test:** in notify_windows/tests.rs, show two popups (hide-all window present), mark both `popup.hide(true, t)` with `t` far enough in the past that the fade is done, call `notify_windows_tick` once: `shown` is empty, `hide_all` is `Some` and hiding, and the step returns `Some(_)` with `windows.clock` not `Stopped`. Then mark the hide-all fade done the same way and tick again: `hide_all` is `None` and the clock is `Stopped`. The first assertion fails with the current code.
