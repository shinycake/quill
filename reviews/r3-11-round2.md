- **20-008: the poll wakes before the answer is applied, so a save or delete now settles up to 2 s late (it was 200 ms).** `quick_replies_pump` reads the session that the main poll pass fills (`settle_quick_reply_save` checks `session.requests.get(request)` and `acks`, `src/ui/quick_replies/mod.rs:297-308`). `quill::wake::UPDATES` is poked by the TDLib receive thread when updates arrive, before any drain (`src/ui/notifications/mod.rs:60-66`). The main poll loop drains them after its 10 ms gap. So both tasks wake on the same poke, the pump usually runs first and finds nothing, sets `seen` to the new epoch (`:368`), and sleeps until the next poke or the 2 s fallback. On a quiet account that is the full 2 s. The comment at `:356-359` ("poke it once the pump drained them") is wrong. Fix (the first review's first option): settle the waiting `PaneStage` from the poll pass after the drain, beside `refetch_open_contacts` (`src/ui/notifications/mod.rs:509`), and drop the task. If the task stays, rest on a signal that is poked after the drain (the pass ends with `CHROME.poke()`, `:511`, or add one for this), not on `UPDATES`. Add a test where the answer is applied after the wake.
- **21-003: the 1 fps app tick redraws the whole app every second, not just the conversation.** `request_animation_tick_for(None, 1, cx)` (`src/ui/secret_chats.rs:123`) leads to `tick_app`, which calls `cx.notify()` (`src/ui/chat_window/cover.rs:363-369`). That notifies every slice of every window (`src/ui/app_slice.rs:15-18`): the sidebar, the composer and the chat windows too. The old task called `notify_conversations`, which redrew only the conversation and composer slices. Fix: target the slice that draws the badges, `self.request_animation_tick_for(self.slices.window.conversation.as_ref().map(|parts| parts.slice.entity_id()), 1, cx)` (the id `notify_conversation` uses, `src/ui/app_slice.rs:414-417`). `None` stays only as the fallback when the conversation is not drawn as slices. The tick is still app-gated, so the hidden-window test keeps passing.
