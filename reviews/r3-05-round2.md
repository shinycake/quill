# Re-review of r3-05 fix round (Opus, 2026-11-12). Verdict: another fix round

Line numbers are on origin/claude/sweep-r3-05.

Resolved from the first review: a menu that another window closes now goes through `close_message_menu` (`src/ui/reactions.rs:52-58`), and a window closed with its menu open forgets the entry (`src/ui/chat_window/mod.rs:681-685`). `MAX_REACTION_ENTRIES` and the retain step are gone (`src/state/media_library.rs:180-187`), and there is a test (`src/ui/chat_window/window_menu_tests.rs:158`). Guards all pass on the tip.

- **08-024: the reaction selector is an exit that still keeps its entry, and the cap that used to hide it is gone.** The menu's "show all reactions" chevron opens the full selector (`src/ui/reactions.rs:673-676`). `open_reaction_selector` closes the menu with the bare `self.message_ui.menu.close_menu()` on purpose, to keep the options (`src/ui/media_panel/mod.rs:313-315`). Nothing forgets the entry when the selector ends: not a pick (`react_from_panel`, `:333-344`), not `close_media_panel` (`:346-357`), and not the one mode writer `set_media_panel_mode` (`src/ui/media_panel/mode.rs:114-135`). So each use of the selector leaves a `Ready` entry for the rest of the session. Now that there is no 16-entry cap, `stale_messages()` (`src/state/media_library.rs:227`) re-sends `getMessageAvailableReactions` for every one of them on each `updateActiveEmojiReactions` / `updateChatAvailableReactions`, and `ready_options()` keeps their custom emoji wanted. This is the unbounded version of the effect the first review described. Fix: in `set_media_panel_mode`, when `old` is `PanelMode::Reaction(target)` and the new mode is not the same target, call `reset_message_reactions(target.chat_id, target.message_id)` on the session in place (live or demo, as `close_message_menu` does at `src/ui/context_menu_keys.rs:430-436`). `forget_chat_window` should also close a selector that is open in that window. Add a test: open the selector from a menu, close it, and the book holds no entry for that message.
