# Review of claude/sweep-r2-07 (round 1): FIX
## Confirmed defects
1. src/ui/updates.rs:32-35 (14-001): check_for_updates returns early on Installed, but UpdateControl::of still maps Installed to Check{busy:false} (src/updater/control.rs:56-61), so the Settings "Check for updates" button looks live and does nothing after an update. Map Installed to a disabled/hidden Check (or post a note on refusal); the button must not look live. Test it.
2. src/ui/send_box_media_check.rs:55-60,100-102 + src/ui/send_box_options.rs:106 (12-D008): the "High quality" offer is lost for photos sent as a converted JPEG. tray_has_large_photo looks sizes up by attachment.photo_file() (the JPEG path once PhotoPrep::Jpeg is set), but the size is read from and stored under the source path (and the image crate often cannot read HEIC). Photos with a JPEG preset skip needs_media_check and never get a size; the timeout path passes size=None and the later real answer is dropped by media.finish. Fix: after check_photo, read dimensions of the file photo_file() returns and key by that path; also size photos that skip the media check; keep a late answer's size. Test it.
