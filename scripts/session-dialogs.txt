# Dialogs whose DialogSpec predicate reads the Session, checked by
# scripts/check-screen-state.py (scripts/session_dialogs.py).
#
# The Session goes to the background with its account and comes back with
# it, so a box whose open flag is the session's is open again on
# switch-back unless a farewell closes it. Each line is
#   Name | closer | reason
# where `closer` is the method an `impl .. Farewell` calls to close it, or
# `-` when the open flag is the screen's (the predicate only reads session
# data) or the box is meant to come back with the account.

AccountExport | - | the box's flag is `dialogs.account_export_dialog` (screen); the progress box shows an export the account is still running, which comes back with it
AccountNotice | - | terms, service notices and the frozen notice are the account's own and stay until answered; the screen-held ones (`login_prevented`, `freeze_info_open`) go with the screen
ArchiveSettings | set_archive_settings_open | `chat_list.archive_settings_open`
BlockFromReplies | close_replies_block | `users_state.replies_block`
BoostBox | close_boost_box_state | `groups.boost_box`
CallLinkLeave | cancel_call_link_leave | `calls.call_link_stage`
CallSwap | - | a second call prompts only during a call, and a switch closes a client that is in a call (retire_live_to_background)
ChatExport | - | the box's flag is `dialogs.chat_export_dialog` (screen); the progress box shows an export the account is still running, which comes back with it
CollectibleInfo | close_collectible_info | `payments.hub.collectible`
CreateChat | - | the box is `admin.create_chat_dialog` (screen); the session holds only the creation step
DropTopic | - | the chooser is `chat_list.drop_topic` (screen)
