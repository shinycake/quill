# The fields inside the app-wide structs of scripts/app-wide-state.txt, one
# by one, with the reason each is the process's and not the account on
# screen's (docs/decisions/account-scoped-ui-state.md, round 6). Checked by
# scripts/check-screen-state.py: a field inside a listed struct (and inside
# the src/ui structs it holds) is either keyed by its account (`AccountKey`,
# `OfAccount`, `AccountChat`, `ConversationKey`, `OwnedBy`) or listed here.
# A name with `*` after it covers the struct it holds as well; use it only
# where nothing inside names an account's ids.
#
#   <struct.field[.field]> [*] | <why it is the process's>

players.audio * | the audio engine: one output device, track and clock for the process; the track is the playback queue's, which is the screen's (PlaybackUi)
players.builds_watched | whether the engine's build watcher is installed, once per process
players.stickers * | the shared sticker player: decoders, frame pump and fixtures keyed by file, not by account; `leave_chat` drops a chat's plays
players.inline_videos | the shared inline video players; their owner is checked each frame (`InlineVideos::own`)
players.inline_videos.state | cleared by `InlineVideos::own` when the account on screen changes
players.userpic_videos * | animated profile photos keyed by local file path (files are per account folder); `UserpicVideos::own` drops the failed list and slots when the account on screen changes
players.speed | the playback speed preference
players.volume | the playback volume preference
players.unmuted_volume | the volume to come back to after unmute
delivery.notify_clicks | OS notification clicks; each `ChatClick` names its account

delivery.next_preview_wait | the delay before the next preview build, for the process
delivery.notification_sounds * | the notification sound output device and player
delivery.polled_redraw * | when the poll loop last redrew: timing, no ids
delivery.windows * | Quill's notification windows; the queue is keyed by `(AccountKey, ChatId)` and each shown popup by its key
preferences.keybinding_capture | the keybinding being recorded in Settings: a key name

preferences.keybindings_applied | whether the keymap was installed, once per process

preferences.system_accent | the OS accent color
preferences.system_accent_probed | whether the OS accent was read
preferences.font_picker | the font family picker entity
preferences.accent_picker | the accent color picker entity
preferences.index_sliders * | slider entities, keyed by setting; most are app settings, but the two storage-limit sliders show one account's TDLib limits, so every arrival on Data and Storage (and every leave) drops them and they are rebuilt from the account shown (`forget_storage_sliders`)
preferences.translate * | the translation preferences file
preferences.update_state | the updater's state, for the install
preferences.update_banner_dismissed | the update banner was dismissed, for the run
preferences.whats_new * | the What's New window and its release notes, for the install
preferences.advanced * | Settings > Advanced: debug codes, test environment, disk-backed demo; values of the install
preferences.emoji_style * | the emoji set and its download, an app-wide asset
frame.animation_demand | how many animations want frames: a count, for the frame clock
