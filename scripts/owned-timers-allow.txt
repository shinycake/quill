# Timers that must run on a clock (scripts/check-owned-timers.py).
# One per line: <rule>:<Type::function> <what ends it, and why it has no event>
poll:run_poll_loop the shared poll loop itself (src/ui/wake_wait.rs): it rests on a quill::wake signal and ends when its pass returns None; the timer is only the gap that gives the thread back between two passes
poll:QuillApp::ensure_self_destruct_tick the countdown badges of the open chat's self-destructing messages: time is the event, there is nothing to subscribe to; the task is the chat's stage (`ChatUi::self_destruct_tick`, dropped with the chat) and ends when no timer is live or the chat is not open
poll:QuillApp::selection_drag_loop the held press's pointer: a pointer resting beyond the list's edge sends no event, yet must keep scrolling and extending the range; the task is the drag's stage (`SelectionDrag::Active`) and ends with the drag, the release or the window losing focus
poll:QuillApp::start_dictionary_download the progress of the dictionary download: the worker thread only advances an atomic byte counter, which has no event; the task is the download's stage (`DictDownload`) and ends when the worker finishes or the stage is replaced
