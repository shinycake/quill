# Native tray and explicit update installation

macOS Appearance settings now offer minimize-to-tray. Both Command-M and the native yellow minimize control hide the application when enabled and a tray is available. Native close and Command-W retain the window; Open Quill restores a minimized or hidden window, and Quit Quill terminates. The default minimize behavior remains native. The PID-isolated, uniquely named smoke app verified all six actions without closing the signed-in app. Other platforms retain their existing tray support; the new minimize setting is macOS-specific.

The updater selects a matching OS/architecture standalone UI asset from the official GitHub release, requiring its advertised SHA-256 digest, expected size and safe release URL. The user explicitly chooses Download, install and restart. A detached helper waits for the old process, verifies size/digest, version and UI build type, replaces the executable beside a rollback backup and relaunches. A failed replacement restores the original. Bundles and Windows retain the release-page download action; the automatic binary installer supports standalone Unix executables. The packaging script emits the matching asset name and checksum.

Downloading, installing, download failure and installation failure are explicit states, with retry where possible. The per-installation receipt preserves release notes and exposes the post-update changelog until dismissal. Startup checking does not overwrite the changelog or installation failure. Native AX checks verified available, failure and installed/changelog controls and release notes. A private binary-copy smoke check exercised the real helper, atomic replacement, relaunch, checksum rejection and preserved original. No live user data was exported or modified by these checks.

Validation: core tests, strict core Clippy, formatting, UI compilation, native tray and updater scripts. The tray proof uses a private ad-hoc signed bundle to avoid macOS scripting resolving duplicate process names to the live app, and services its runloop while observing native visibility state.
