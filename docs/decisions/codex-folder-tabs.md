# Folder tabs

The folder strip (All, user folders, Unread, Archived) clipped its trailing tabs with no way to see them. It now uses the kit TabBar's own overflow support: underline style (lighter than boxed tabs, more fit), names truncated at 140px, and the overflow menu (`menu(true)`) that lists every tab by its full name. The folder-manage button is a settings icon with a tooltip, distinct from the overflow chevron; it used to be a second "⋯". The main menu button is the Menu icon instead of a "☰" text glyph.
