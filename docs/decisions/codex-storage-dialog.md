# codex/storage-dialog — Data & Storage dialog actions

- The footer follows the dialog convention: an outline "Refresh" plus a primary "Done" (was two
  ghost text buttons, "Refresh" and "Close"). The network editor's "Save" is primary.
- The two export choices sit side by side as small outline buttons instead of two full-width
  stacked buttons. "Show export folder" is outline and Cancel/Dismiss is ghost.
