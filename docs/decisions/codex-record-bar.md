# codex/record-bar — one-row recording bar

- The voice/video recording bar is a single row: a pulsing red dot, the elapsed time, the live
  waveform (or "Video message"), then icon actions: lock (shown `selected` while locked), discard
  (trash) and a round primary send. It replaces the red-bordered card with a "Recording voice ·
  0:02 · locked" title and Unlock/Cancel/Send text buttons.
- The discard confirmation reads "Discard recording?" with a small danger "Discard" and a ghost
  "Keep".
- The input row stays visible below the bar: the mic button drives hold-to-record, so hiding it
  mid-press could drop the release.
