# Service messages (gap-audit batch 3)

## Decision

Every TDLib `MessageContent` constructor that is a chat event now parses into
`MessageContent::Action(Box<ServiceAction>)` (structured facts only:
`src/telegram/envelope/service_action.rs`). The wording is generated by one
pure module, `src/service_text.rs`, from Telegram Desktop's
`HistoryItem::setServiceMessageByAction` / `prepare*Text` and the `lng_action_*`
strings. It returns a `ServiceText` (segments, some carrying a
`ServiceLink`: profile of a user/chat, jump to a message, external URL) that the
history pill and the chat-list preview both use.

- Names come through the `ServiceNames` trait (`Session` implements it in
  `state/session_service.rs`): user/chat names, short names for gift lines,
  the pinned message (text excerpt cut at 16 characters like tdesktop, or the
  media phrase "a photo"/"a voice message"...), game titles.
- The history row (`ui/service_row.rs`) is a centered, wrapping pill; names,
  the pinned excerpt and game titles are accent colored and clickable
  (profile modal / jump to message / open URL). Chat-photo changes and
  suggested profile photos show the new photo as a round tile under the pill
  that opens the media viewer (and is auto-downloaded).
- Chat-list previews use the same text (`set_chat_last_message`); the row
  drops the "Dana:" prefix for service previews (`ChatPreviewStyle.service`).
- The old `MessageContent::Service(String)` is gone. `ChatTtlChanged` and
  `ScreenshotTaken` keep their variants but are worded by the generator.
  Calls, group-call invitations, communities, invoices and payment receipts
  keep their dedicated rows.

## Known simplifications

- Pinned excerpt needs the pinned message in the loaded history; otherwise the
  row says "pinned a message" (still jumps). No `getMessage` fetch here (batch 2
  owns fetching replied messages).
- The chat-list preview is computed when the last message arrives; if a name
  was not cached yet it reads "Someone" until the next update of that chat.
- Checklist done/undone rows say "2 tasks" rather than naming tasks; gift,
  giveaway and star-gift cards are one-line text, not tdesktop's cards.
- Wallpaper rows have no "View wallpaper" button and cannot tell "same
  wallpaper" apart (TDLib does not say).
