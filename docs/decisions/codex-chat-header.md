# Chat header

Every chat kind gets the same identity block: avatar, title, and one status line chosen by priority. Activity ("typing…", "choosing a sticker…") comes first, then secret-chat state, then presence for private chats ("online" in the accent color, "last seen …", "bot"), then member or subscriber count and @username for groups and channels, then muted, then the auto-delete timer. Before, only channels had an avatar; private chats had a bare title, and several status lines could stack. The channel description snippet left the header (the info panel shows it). The whole block opens the chat's info panel for users, supergroups and basic groups.

Header actions are icons: Call (private chats with users who can be called), Voice chat (groups and channels, highlighted while one is live), Search this chat, then the "⋯" chat menu last. The duplicate title-bar "Find in chat" button is gone; the title bar keeps global search only.
