# Composer polish

The composer is one row: attach, emoji/stickers, formatting ("Aa" icon menu), the auto-growing input (1–8 lines, previously at least 2), record, send.

Send options moved off the permanent "Aa · 🔕 Silent · ⏰ Schedule · 🔗 Preview" toolbar into a right-click menu on Send, as in the official desktop client: "Send without sound", "Schedule message…" and "Link preview" (checkable). Non-default options stay visible as small clearable chips above the input (Silent, Scheduled · date, When online, No link preview), so hidden state never surprises the user. The rich-editor entry keeps its place in that row when a draft passes three lines.

Reply, edit and delete-confirm banners share one slim context bar: an icon, a colored rule, title and one-line preview, and a close button, replacing full red, yellow and accent bordered boxes. Delete uses a "Delete for everyone" checkbox (only where `can_revoke`) and a danger button, instead of a floating "For me / For everyone" toggle label.

Out of scope: the accent palette (yellow accent vs blue bubbles) gets its own theme pass.
