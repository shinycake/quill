# Sticker panel and picker placement

The sticker panel mixed the picker with management: labels like "Installed · open" / "· selected", a "Suggest by emoji:" button row, "Install N displayed sets", "Remove all installed", per-set "Archive" buttons and a "Favorite/Unfavorite" text button under every sticker. It's now a picker first:

- Tabs show their selected state with the kit's selected style. A "⋯" overflow menu holds the suggestion mode (checkable), "Clear recent stickers", "Add N sets shown" and "Remove all installed sets…". The close button is an icon.
- Sets are a strip of compact chips (tooltip shows the count; drag to reorder in Installed). The selected set's header carries Add/Remove and Archive.
- Favoriting is a right-click menu on the sticker.
- The status line only appears for loading, failure and empty states.

Reaction, emoji, GIF and sticker pickers now open directly above the composer, next to the buttons that open them, instead of at the top of the history pane. The reaction picker's text "Close" becomes an icon.
