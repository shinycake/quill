# codex/album-actions — albums use the hover actions menu

- Album bubbles drop their inline ghost "Reply" button. Like single messages, they show the
  round "…" actions button beside the bubble on hover, which opens the message menu for the
  album's first message.
- Albums are media-led: thin inset around the mosaic, caption padded under it, and the time
  overlaid on the picture when there is no caption.
- `message_actions_button` is shared between single rows and albums.
