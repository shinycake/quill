# Rust 1.100

## What tdesktop does

Nothing relevant. This is Quill's own toolchain pin (`docs/dependency-updates.md`).

## What changed

The pin moves from 1.99.1 to 1.100.0 in `rust-toolchain.toml`, `docs/build.md`, `README.md`
and every `toolchain:` line in the CI and packaging workflows. The MSRV (`rust-version` in
all five Cargo.toml files) moves from 1.92 to 1.100: Quill now calls std APIs that are new in
1.100, and clippy's MSRV-aware lints read `rust-version`, so a lower value hid suggestions
for APIs the pinned toolchain already has.

What Quill adopts from 1.100:

- **Cargo's `unused_dependencies` lint, set to `deny`** in `[workspace.lints.cargo]`. It
  found `tar`, which only the Linux and Windows updater uses (`src/update_install/bundle.rs`
  is not built on macOS) and which every macOS build compiled for nothing. It now sits in a
  `cfg(not(target_os = "macos"))` table. A dependency that stops being used now fails the
  build on the platform where it is unused.
- **Dependency cooldown.** `.cargo/config.toml` sets
  `registry.global-min-publish-age = "3 days"`, so `cargo update` and new dependencies skip
  crate versions published in the last three days unless they are already in `Cargo.lock`.
  A hijacked or broken release usually gets yanked within that window. Three days, not the
  documented seven, because Quill takes GPUI Kit releases quickly; a same-day update is
  still possible on purpose with `CARGO_RESOLVER_INCOMPATIBLE_PUBLISH_AGE=allow`
  (`docs/dependency-updates.md`).
- **`core::mem::DropGuard`** replaces four hand-written guard types whose only job was to
  run one closure on drop: the chat palette restore (`ui/chat_palette.rs`), the half-written
  rich HTML export folder (`rich_html/worker.rs`, `DropGuard::dismiss` keeps it) and the two
  receive-loop stop guards (`telegram/client.rs`, `telegram/hub.rs`). Guards with more state
  or a name other code uses (`PinGuard`, `WarmGuard`, `ScanGuard`, `RefreshGuard`) stay.
- **`str::trim_prefix` / `trim_suffix`** replace the 29 `x.strip_prefix(p).unwrap_or(x)`
  spellings.
- **`bool::toggle`** replaces the 22 `x = !x` flips.

Checked and not adopted: custom allocators (`Allocator`, `Vec::new_in`; no hot path in
Quill allocates in a pattern an arena would fix today), the stable never type (no API of
Quill's returns `Result<_, Infallible>` in a way that reads better as `!`),
`CommandExt::show_window` (Quill's Windows spawns set `CREATE_NO_WINDOW`, a creation flag,
not a show state), and `extern "custom"`. 1.100 also moves Cargo's intermediate build
files to a new layout; no Quill script reads `target/*/build` or `target/*/deps`.

## How verified

On 1.100.0: core clippy (`--no-default-features --all-targets -D warnings`), UI clippy with
`demo-capture`, core and UI tests, the repo CI scripts. No new compiler or clippy lints
fired besides the unused `tar` dependency. Linux and Windows build in PR CI.
