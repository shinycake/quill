# Rust 1.99.1

## What tdesktop does

Nothing relevant. This is Quill's own toolchain pin (`docs/dependency-updates.md`).

## What changed

The pin moves from 1.99.0 to 1.99.1 in `rust-toolchain.toml`, `docs/build.md`, `README.md`
and the CI and packaging workflows (`ci.yml` three times, `macos-smoke-fallback.yml`,
`package-{linux,macos,windows}.yml`). The MSRV (1.92) is unchanged.

1.99.1 fixes a miscompilation of FFI `bool` return values on x86_64
(rust-lang/rust#163911). Quill calls TDLib, ntgcalls and the platform APIs through FFI,
and the Windows and Linux x86_64 builds use that target. It also adds the `libLLVM` rpath
for `rust-lld` on macOS and fixes a missing `wcslen` on UEFI targets, which Quill does not
build.

## How verified

Gate on 1.99.1 (fmt, core and UI clippy with `-D warnings`, core and UI tests). No new
lints fired. CI covers the Linux build; packaging covers Windows and macOS after merge.
