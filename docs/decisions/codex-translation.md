## Batch 7 — Translation (2026-10-08)

- **Scope:** gap-audit batch 7. Translate and Translate Selected Text in the message menu, the translate box, the chat translate bar with translated bubbles, and the translation options in Settings. Reference: tdesktop `boxes/translate_box.cpp`, `boxes/translate_box_content.cpp`, `history/view/history_view_translate_bar.cpp`, `history/view/history_view_translate_tracker.cpp`, `boxes/language_box.cpp` (the options live in its Language box).
- **TDLib surface used:** `translateMessageText` (whole message, formatting kept for Premium), `translateText` (a selection), `chat.is_translatable` / `updateChatIsTranslatable`. Not used: `translateRichMessage` / `translateMessageRichMessage` (Quill's rich messages translate through their text), `translateText.tone` (always empty = neutral).
- **Verified gaps first:** nothing translation-related existed (only `composeTextWithAi`'s unused `translate_to_language_code`). The schema has no `toggleChatIsTranslatable` and no language recognition, which shaped three decisions below.

### Decisions

1. **Language guess is local and dependency-free** (`translate::detect_language`). TDLib offers no recognizer; tdesktop uses the OS one (`Platform::Language::Recognize`), which is not on every OS Quill ships on. The guess reads Unicode script first (Hebrew, Greek, Hangul, Thai, the Indic scripts, Georgian, Armenian, kana vs Han, Arabic split into ar/fa/ur/ps by letters, Cyrillic into ru/uk/be/sr/mk/kk) and scores common words and diacritics for 15 Latin-script languages. It returns `None` for short or ambiguous text, and every consumer treats `None` as "do not decide" (the menu then offers Translate, the bar does not count it). A crate such as `whatlang` would cover more languages; skipped to keep the dependency list and `THIRD_PARTY.md` unchanged. Easy to swap: one function.
2. **Offer rule copied from `TranslateTracker::checkRecognized`** (`translate::offer_language`): the newest 100 incoming messages with text, at least 6 of them, and 6 of every 10 in a language that is not in "Do Not Translate"; the most common such language is offered.
3. **Bar gating follows tdesktop and TDLib.** The bar needs all of: "Translate Entire Chats" on, an account with Premium (`is_premium` option), `chat.is_translatable` from TDLib, the chat not hidden by the user, not a secret chat, and an offered language. tdesktop's other path (channels with automatic translation) is not wired: `supergroup.has_automatic_translation` is not parsed, so the bar is Premium-only (a documented gap, not a silent one). The upsell is tdesktop's: the "Translate Entire Chats" switch is locked for non-Premium accounts and says so; a click shows "Translating entire chats requires Telegram Premium" (tdesktop opens its Premium preview, Quill has no Premium purchase flow).
4. **"Hide" is local.** tdesktop writes `messages.togglePeerTranslations` (the server flag TDLib reflects as `is_translatable`). TDLib 1.8.67 has no setter, so hiding is stored per chat in `translate_prefs.json` and does not sync to other clients. The Undo toast and the group/channel/chat wording follow tdesktop.
5. **Translate box** is a kit dialog (`DialogKind::Translate`): original text (three lines, "Show" for more), divider, target language name with a Copy button (hidden in protected chats, like `hasCopyRestriction`), the translation or a grey placeholder or "Translate failed.", and Language / OK buttons. The language chooser is a page of the same dialog (search + list) so dialogs never stack. Original and translation are drawn with `rich_text_line`, the message renderer, so entities, links and the bidi/RTL layout paths apply unchanged.
6. **Whole message vs selection.** Translate on a message sends `translateMessageText` (TDLib extracts text or caption and keeps formatting for Premium); Translate Selected Text sends `translateText` with the plain selection (a selection carries no entities). Results are keyed per `(chat, message, language)` or per job, never overwritten by a later request for another language.
7. **Translated chat** replaces text and captions of incoming messages in the rendered rows only (`HistoryRowsKey` carries `translate.revision`); stored messages, reply strips, chat-list previews and notifications keep the original. The pump (`pump_translation`, in the poll tick) requests up to 20 untranslated incoming messages at a time, newest first, skips messages already in the target or a skipped language, follows a changed "Translate to" language, and reverts when the bar stops being offered (tdesktop `stopAndRevert`). Outgoing messages are not translated (tdesktop: only with channel auto-translation).
8. **Settings** sit in the Appearance dialog next to the other chat options (Quill has no separate Chat Settings or Language screen; tdesktop has them in Settings > Language): Show Translate Button, Translate Entire Chats, Do Not Translate. Defaults follow tdesktop: button on, chats off, "Translate to" and "Do Not Translate" start as the app language; the last skipped language cannot be removed ("Please choose at least one language…").
9. **Cocoon** (tdesktop's bar-menu footer about Telegram's translation backend) is left out: it is branding for tdesktop's own provider choice.
10. **Not done:** tdesktop's platform translation provider ("Use Apple Translations" / KDE Crow), `lng_translate_box_error_language_pack_not_installed`, the Premium-only formatting note, summaries (`summarizeMessage`).

### Tests

- Core: language table and normalization, script and word detection, prefs defaults/round-trip/skip-list rules, `choose_translate_to`, `skip_translate`, `offer_language`, text/caption replacement (`src/translate.rs`).
- Requests: `translateText`, `translateMessageText` shapes (`telegram/requests/translate.rs`).
- Recorded-JSON request/answer tests through the driver (`connect/tests/translate.rs`): the message request, the `formattedText` answer with a bold entity, per-language keys, duplicate suppression, a failed request and its retry, a selection job, `updateChatIsTranslatable`, the chat's translated-to state and revision.
- Demo captures (`ready-translate`, light and dark): bar, translated chat, box, Hebrew (RTL) box, selection box, chooser, skip list, settings.

### Check live

Translate on an incoming message in a foreign-language chat (box, copy, change language); Translate Selected Text over a drag selection; with a Premium account and "Translate Entire Chats" on: the bar in a chat of foreign messages, switching to the translated bubbles and back, Translate To, Don't translate, Hide and Undo; with a non-Premium account: the locked switch. `chat.is_translatable` should be true for chats where Telegram has not disabled translation.
