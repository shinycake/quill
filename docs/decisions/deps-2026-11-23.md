# Dependency round, 2026-11-23

This round covers the five deps-watch issues open on 2026-11-23: #1499 (TDLib),
#1500 (gpui-kit), #1501 (Cargo), #1502 (FFmpeg) and #1503 (ThorVG). Each
dependency below lists what moved, what Quill gets out of it and what it
left out on purpose. The two big ones have their own notes:
[gpui-kit 0.11.0](gpui-kit-0-11-0.md) and [TDLib 1.8.71](tdlib-1-8-71.md).

## TDLib 1.8.70 → 1.8.71 (#1499)

Pin `23383aef` → `1b9efe84`, schema 68 added, 2 removed, 14 changed. Every
constructor is in [tdlib-1-8-71.md](tdlib-1-8-71.md).

What Quill gains:

- **Bot invites, the tdesktop way.** A bot owner can invite up to ten people
  from the bot's profile or from an invite link ("Invite to Bot" box). Someone
  who was invited sees "{user} invited you to this bot" in the chat, plus a bar
  with Block bot / Report Spam. Report Spam reports the inviter, as TDLib
  documents. Invite links show an "Invite to Bot" button in the link preview.
- **One request for media counts.** The info panel used to send seven
  `getChatMessageCount` requests each time it opened, and the shared media
  gallery sent two more. Now each sends one `getChatMessageCounts`.
- **On-chain gifts read correctly.** Offers paid from a TON wallet show as
  service text ("You offered 40 Grams for …", "This offer was accepted."), and
  gifts bought on chain show their Gram price. Own gifts listed for on-chain
  resale point to the official apps instead of offering a resale Quill can't
  complete.
- Renames kept working: `getGiftMintingUrl` (was `getUpgradedGiftWithdrawalUrl`),
  `mint_date`, `min_price` (without this rename the "Minimum price" row would
  have vanished without any error), and expandable block quotes that now hold
  blocks.

Not adopted, on purpose: every TON action (on-chain offers, `mintGift`,
`withdrawGrams`, wallet transactions), per the no-TON rule. The agent policy
blocks those methods. Also not adopted: API that tdesktop doesn't use (listed in
the TDLib note).

Platforms: tested on macOS (unit tests and demo screenshots). The TDLib build
for Linux and Windows is only built by CI.

## gpui-kit 0.10.0 → 0.11.0, gpui-pre 0.3.12 → 0.3.14 (#1500)

All seven vendored GUI crates were re-vendored. Each one is a pristine commit
plus a patch commit. Quill's menu patch in gpui-component survived the
re-vendor unchanged. Details: [gpui-kit-0-11-0.md](gpui-kit-0-11-0.md).

What Quill gains:

- **Memory:** the Metal renderer no longer keeps a window-sized texture for
  paths. In the glass demo, memory dropped from 88–89 MB to 71–72 MB (debug
  builds, 3 alternating runs each, `footprint`). Screens that never draw a
  path don't change.
- **Path drawing:** paths are now drawn from analytic tile coverage instead of
  a multisampled texture. Every main screen is pixel-identical before and
  after, except 16 edge pixels on the story rings.
- Kit fixes reach Quill with no code change: notifications stay above dialogs,
  menus that fit drop their scrollbar, the input ends IME composition on
  blur, masked fields (cloud password) hide their text from the IME,
  Ctrl+Delete stops at spaces, and large drafts keep less accessibility
  memory.
- The search's "Show more / Collapse" link now tells screen readers whether
  the grid is expanded, using the kit's new expanded state on Button.
- One carry bug was found and fixed: under the new deferred layers, a nested
  layer could draw under its parent. There is a test for it.

Not adopted, and why: the input suggestion list, `reveal_range`, the
left-side scrollbar, DockSkin, resizable drag state and kit `Presence`. Quill
has its own versions of each, or doesn't use the component.

Platforms: the Linux and Windows parts of the re-vendor were cross-checked
with clippy only and never ran on those systems. **Experimental** until CI
and a real Linux/Windows run confirm them.

## Cargo (#1501)

50 compatible updates, plus qrcode 0.14 → 0.15. They are patch and minor
releases. None of them adds API that Quill needed to adopt, so what Quill gets
is upstream's bug fixes. The direct and user-facing ones: zip 9.5.1 → 9.8.1
(updates, lang packs), fast_image_resize 6.1 → 6.2 (thumbnails), rusty-opus
1.1 → 1.2 (voice messages), zbus 6.3 → 6.5 (Linux portals), wry 0.57.3 and
tao 0.37.3 (message widgets), rand, regex, clap, uuid and zeroize. qrcode
0.15 is a cleanup release, and the three QR paths compile unchanged.

Some versions are still inside the 3-day cooldown and wait for the next round:
zip 9.8.2, ashpd 0.14.3 and rusty-opus 1.2.1. gpui-fast moved in the lockfile
only, because Quill doesn't turn on that kit feature.

`url` advisory: main was already on url 2.5.9, so there was nothing to do.

## FFmpeg n9.0.2 → n9.1 (#1502)

Library majors are unchanged (avcodec 63, avformat 63, avutil 61), so
quillvideo and the call library need no changes.

What Quill gains: FFmpeg's reworked AAC encoder, used by the video editor,
round videos and downscale encodes, plus the release's decoder fixes. The 99
real-decoder tests pass against a macOS build (`QUILL_REQUIRE_VIDEO_LIB=1`).

Not adopted: nothing new is needed from n9.1's added codecs and filters.
Quill decodes what Telegram sends.

Platforms: built and tested on macOS only. Linux and Windows builds come from
CI and are **experimental** until they run on those systems.

## ThorVG v1.1.3 → v1.1.4 (#1503)

What Quill gains: fixes for four Lottie security advisories,
GHSA-v74h-2xm8-vx3j, GHSA-7m5w-c3mj-r673, GHSA-72m2-xw35-rrv3 and
GHSA-693j-3439-j9m5. A hostile sticker could have used them. Two of Quill's
own sticker guards are now upstream, so the patch shrinks: the precomp cycle
guard and the gradient stop count. The repeater limit now checks the whole
chain before the first copy.

Upstream moved its loaders to `src/modules`. The vendor script, build.rs and
the license staging scripts follow that move. Golden sticker frames are
byte-identical.

## How verified

- Gate (fmt, both clippies, core and UI tests, license list) passed on the
  combined tree. All `scripts/check-*.py` and `check-file-size.sh` pass.
- Mac demo screenshots: sticker playback, animated emoji, stickers, QR login,
  bot invite bar, Invite to Bot box (clicks on rows and ticks), bot profile,
  on-chain gift texts.
- Kit before/after captures in light and dark, plus the memory runs above.
