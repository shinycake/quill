Early preview · open source

An alternative native desktop client for Telegram, written in Rust and GPUI.

Quill runs on macOS, Windows and Linux and draws its whole interface on the GPU. It talks to Telegram through the official TDLib library, so your chats, contacts and account are the real thing.

Everything you use every day

Quill is built from scratch, but it isn't a toy. Most of what you do in Telegram on a desktop already works.

Messaging

Bold, italic, code, spoilers, quotes and links. Replies and quote-replies, forwarding, scheduled and silent messages, cloud drafts, reactions and polls.

Media

Photos, videos, albums, GIFs and stickers. Voice and video messages recorded right in the app, with transcription. A fullscreen viewer, an audio player bar and a downloads list.

Calls

One-to-one audio and video calls with screen sharing, and group voice chats.

Groups & channels

Admin tools, invite links, join requests, forum topics, comments, and channel statistics. Bots with keyboards, inline results and games.

Privacy

Secret chats, a local passcode lock, active-session management and two-step verification. No analytics: apart from Telegram, Quill only contacts GitHub to look for updates, and you can switch that off.

Make it yours

Light and dark themes with automatic night mode, accent colors, chat wallpapers, text size, and bubble or plain message layouts.

How it's built

TDLib does the talking

Quill doesn't reimplement Telegram's protocol. Every request goes through TDLib, Telegram's own client library, the same one many third-party apps use. Encryption, sync and the local message database are TDLib's job.

GPUI draws the window

The interface is native Rust on GPUI, the GPU-accelerated UI framework from the Zed editor. There's no browser engine and no web view inside.

Open, and checkable

The source is on GitHub under the MIT license. Every third-party component and its license is listed in the repository and inside the app under Settings → Appearance → About Quill.

Installing Quill

On a Mac

Recommended

Install with one Terminal command

Quill installs in Applications and opens straight away, without the “Apple could not verify” warning. Run the same command later to update.

  1. Open Terminal: press ⌘ Space, type Terminal and press Return.
  2. Paste this command and press Return:
    curl -fsSL https://raw.githubusercontent.com/shinycake/quill/main/scripts/macos-install.sh | bash
  3. Quill opens when it's done.
Why it's safe
  • You can read it. The installer is a short, open-source script. Read it on GitHub before you run it, like the rest of Quill.
  • It only downloads Quill. It fetches the same file as the download button below, from Quill's official GitHub releases.
  • It checks the download. It compares the file's fingerprint (a SHA-256 checksum) with the one published with the release, and checks that the app's code signature is intact. If anything doesn't match, it stops and installs nothing.
  • It changes nothing else. No administrator password, no background services, and no Mac security settings are touched. It puts Quill.app in Applications and nothing more.

Why there's no warning: macOS checks apps you download in a browser. Quill isn't checked by Apple yet, because that needs a paid Apple developer account, so the browser download below asks you to confirm it once. Files that Terminal downloads aren't marked for that check.

On Windows

Recommended

Install with one PowerShell command

Quill installs for your account and starts straight away, without the “Windows protected your PC” warning. Run the same command later to update.

  1. Open PowerShell: press ⊞ Win, type PowerShell and press Enter.
  2. Paste this command and press Enter:
    irm https://raw.githubusercontent.com/shinycake/quill/main/scripts/windows-install.ps1 | iex
  3. Quill starts when it's done. From then on it's in the Start menu.
Why it's safe
  • You can read it. The installer is a short, open-source script. Read it on GitHub before you run it, like the rest of Quill.
  • It only downloads Quill. It fetches the same file as the download button below, from Quill's official GitHub releases.
  • It checks the download. It compares the file's fingerprint (a SHA-256 checksum) with the one published with the release. If they don't match, it stops and installs nothing.
  • It changes nothing else. No administrator rights and no background services, and no Windows security settings are touched. It puts Quill in your user folder, adds it to the Start menu, and you can remove it in Settings → Apps.

Why there's no warning: Windows SmartScreen checks programs you download in a browser. Quill isn't signed with a paid Microsoft certificate yet, so the zip below asks you to confirm it once. Files that PowerShell downloads aren't marked for that check. If Smart App Control is turned on (Windows 11), it may still block Quill, because it checks every app.

On Linux

Recommended

Install with one terminal command

Quill installs for your account, shows up in your applications menu and opens straight away. Run the same command later to update.

  1. Open a terminal.
  2. Paste this command and press Enter:
    curl -fsSL https://raw.githubusercontent.com/shinycake/quill/main/scripts/linux-web-install.sh | bash
  3. Quill opens when it's done. If your system is missing a library Quill needs, the installer names it instead.
Why it's safe
  • You can read it. The installer is a short, open-source script. Read it on GitHub before you run it, like the rest of Quill.
  • It only downloads Quill. It fetches the same file as the download button below, from Quill's official GitHub releases.
  • It checks the download. It compares the file's fingerprint (a SHA-256 checksum) with the one published with the release. If they don't match, it stops and installs nothing.
  • It changes nothing else. No sudo or root password, and nothing outside your home folder. Quill goes in ~/.local, and ~/.local/opt/quill/install.sh --uninstall removes it.

Or download it yourself

Get Quill as a tarball. It runs from any folder, or installs under ~/.local.

Download for x86_64 (tar.gz) Download for arm64 (tar.gz)
How to install it
  1. Unpack it: tar -xzf quill-linux-*-bundle.tar.gz
  2. Run quill-linux-*/install.sh to add Quill to your applications menu, or start quill-linux-*/quill where it is.

Quill needs a glibc-based distribution on x86_64 or 64-bit ARM (arm64), a Vulkan driver, and GTK 3, which every mainstream desktop has. On a minimal Debian or Ubuntu system, install them with sudo apt install libgtk-3-0 libxkbcommon-x11-0 libvulkan1 mesa-vulkan-drivers libfontconfig1 libasound2.

Questions

Is Quill made by Telegram?

No. Quill is an independent project. It isn't affiliated with, endorsed by, or sponsored by Telegram. It uses the public Telegram API under Telegram's API Terms of Service, through Telegram's own TDLib library.

Can my account get banned for using it?

Quill follows Telegram's rules for third-party apps as closely as we can, but Telegram decides what it allows, and we can't promise anything. Quill is experimental: use it at your own risk.

Does Quill see my messages?

Quill runs on your computer and stores its data there, encrypted with a key kept in your system's keychain (macOS), DPAPI (Windows) or a private file (Linux). It has no server of its own and collects no analytics.

Why do I need to confirm the first launch?

Releases aren't signed with a paid Apple or Microsoft certificate yet. On macOS, install with the Terminal command and there's nothing to confirm, because macOS only checks apps downloaded in a browser. If you downloaded the zip, follow the steps to open it once. On Windows, install with the PowerShell command and SmartScreen has nothing to confirm, because it only checks programs downloaded in a browser (Smart App Control, if you turned it on, is a separate check). If you downloaded the zip, choose More info → Run anyway once. Each release lists SHA-256 checksums so you can verify the download.

How can I help?

Try it, and open an issue when something breaks or feels off. Pull requests are welcome too.
