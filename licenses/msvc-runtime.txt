Microsoft Visual C++ runtime (Windows package only)

quill.exe, tdjson.dll and rlottie.dll are built with Microsoft Visual C++ and
link the C/C++ runtime statically (/MT; Rust's +crt-static), so the Windows
package ships no vcruntime140*.dll or msvcp140*.dll and needs no Visual C++
Redistributable. ntgcalls.dll (upstream prebuilt) also links it statically.

The runtime library code linked into those files is Microsoft's. It is
distributed as part of the program under the Microsoft Visual Studio license
terms (https://visualstudio.microsoft.com/license-terms/), not under Quill's
MIT license, and remains the property of Microsoft Corporation. See also
https://learn.microsoft.com/cpp/c-runtime-library/crt-library-features.

The Universal CRT (ucrtbase.dll, api-ms-win-crt-*.dll) used by the FFmpeg
DLLs is part of Windows 10 and later and is not shipped.
