Components inside the ntgcalls library (libntgcalls.so / libntgcalls.dylib / ntgcalls.dll)

Quill ships the official prebuilt ntgcalls v3.0.2 shared library unmodified
(scripts/vendor-ntgcalls.sh, SHA256-pinned). ntgcalls itself is LGPL-3.0
(ntgcalls-LGPL-3.0.txt). According to its build files at tag v3.0.2
(CMakeLists.txt, wrtc/CMakeLists.txt, cmake/*.cmake, version.properties), the
library statically links the components below. Versions are the ones pinned in
version.properties at that tag.

The OpenH264 code in ntgcalls is compiled from source by the ntgcalls project.
Cisco's OpenH264 patent license covers only binaries that Cisco itself
distributes, so it does not apply to this library.

The complete corresponding source for the LGPL components (ntgcalls, FFmpeg,
GLib) is available from the upstream locations above. You may replace the
ntgcalls library in the Quill package with your own compatible build; Quill
loads it at runtime and does not link it at build time.
